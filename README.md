
# CodeAlpha Web Scraping Project

## Project Description
This project collects book details from a website using Python Web Scraping.

## Technologies Used
- Python
- Requests
- BeautifulSoup
- Pandas

## Data Collected
- Book Name
- Book Price
- Availability

## Output
The extracted data is saved in books_data.csv.

## How to Run
1. Install required libraries:
   pip3 install requests beautifulsoup4 pandas

2. Run the program:
   python3 web_scraping.py
